**https://apexsans.com**

## 라이선스와 구매

기본 라이선스 150,000원(VAT 포함). 인쇄물, 웹사이트·앱 이미지, 일반 문서, 소규모 상호·간판, 상업용 제품, 영상물에 사용할 수 있습니다. CI/BI와 앱 UI·기기 임베딩은 별도 문의입니다. 결제는 계좌이체만 가능합니다(카드 결제는 추후 지원 예정).

라이선스 전문과 구매 문의는 사이트의 Credit 섹션에 있습니다.
문의: mail@apexsans.com

## 저장소

빌드 단계 없이 저장소 전체를 정적 호스팅(GitHub Pages)으로 내보냅니다. 바닐라 HTML / CSS / JS입니다.

```
index.html      사이트 본문
404.html        없는 주소 안내
assets/         스타일, 스크립트, 서체, 이미지
docs/           JSON-LD 예시 등 참고 문서
CNAME           apexsans.com
robots.txt  sitemap.xml  llms.txt
```

웹에 올라간 서체 파일(`assets/fonts/ApexSans-Regular.woff2`)은 이름이 `APEX SANS Trial`로 표기된 미리보기용입니다. 설치·재배포는 허용되지 않습니다.

## 저작권

서체와 이 페이지의 글·이미지는 박창규에게 저작권이 있습니다.
